# src/commands

## Purpose

Command implementations for the reposell CLI — one module per command, composable and single-responsibility.

## Ownership

Owner: src/commands (inherits ../../AGENTS.md)

## Responsibilities

- Commands: `init`, `publish`, `release`, `build`, `validate`, `health`, `verify`, `keys`, `license` (+`license-args`), `listing` (+`listing-publish`), `sell-create-link`, `sell-sync`, `audit`, `balance`, `reciprocity`, `evaluation-format`.

## Inputs

- Parsed CLI arguments, configuration, environment.

## Outputs

- Formatted human/JSON output; delegated work to `src/app` services.

## Dependencies

- src/app, src/config, src/cli, src/domain
- .github/workflows (generated by `init`)
- .github/

## Constraints

- Commands orchestrate services; no business logic beyond argument handling and formatting.
- Tests are co-located (`*.test.ts`).
