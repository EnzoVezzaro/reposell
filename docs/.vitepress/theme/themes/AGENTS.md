# docs/.vitepress/theme/themes

## Purpose

The four exclusive visual theme layers loaded by the theme switcher.

## Ownership

Owner: docs/.vitepress/theme/themes (inherits ../AGENTS.md)

## Structure

- `security/` — terminal/decrypt aesthetic.
- `shadcn/` — editorial aesthetic.
- `canvas/` — orbit/glass aesthetic.
- `cartoon/` — comic/sticker aesthetic.

## Constraints

- Exactly one theme active at a time (`data-theme` scope); layers must not leak styles.
